# Промты этапов (готовые к исполнению)

## Этап 10a — Торговая сводка на звёздной карте («рыночная разведка»)

### Контекст проекта
Браузерная 2D космопесочница «Космический Рейнджер»: React 19 + Canvas 2D + TypeScript + Vite,
рабочая папка `E:\Рейнджеры\app`. Игра живёт в `src/game/` (game.ts — оркестратор ~3200 строк,
economy.ts, world.ts, fleet.ts, missions.ts, render.ts, save.ts, uiBridge.ts), UI — в `src/ui/*.tsx`.
План работ — `PLAN.md`; этот пункт там называется «10a. Торговая сводка на звёздной карте».

### Проблема
Цены на рынках игрок видит только пока пристыкован к станции. Торговля держится на памяти
игрока: где он видел дешёвую руду — неизвестно, приходится летать вслепую.

### Цель
На звёздной карте (клавиша M, `src/ui/StarMap.tsx`) появляется торговая сводка: для каждой
станции, где игрок ХОТЬ РАЗ стыковался, — последние увиденные цены покупки/продажи по всем
товарам и пометка давности наблюдения. Станции без визита — «нет данных».

### Ключевые точки в коде
- `src/game/uiBridge.ts` — интерфейс `MapSnapshot` (строка ~45): сюда добавить поле intel.
  `StationSnapshot.prices: Record<string, { buy; sell }>` (строка ~79) — формат цен, переиспользовать его.
- `src/game/game.ts` — снапшот станции собирается около строки ~2697 (`prices[g.id] = {...}`);
  стыковка — метод `dock()`. Здесь же записывать наблюдение.
- `src/game/types.ts` — `SaveGame` (строка ~296, рядом `fluct`): добавить поле intel в сейв.
- `src/game/save.ts` — `SAVE_VERSION` (сейчас 8) и `validateSave`: поднять версию до 9,
  старые сейвы v8 принимать с пустой разведкой (обратная совместимость обязательна).
- Цены дрейфуют: `world.ts` (~строка 144) крутит `fluct` каждый тик — значит данные стареют,
  это нормально и должно быть видно игроку.

### Реализация
1. **Состояние.** В Game: `marketIntel: Record<dockableId, { t: number; prices: Record<goodId, { buy: number; sell: number }> }>`,
   где `t` — игровое время наблюдения (`player.playTime`, секунды). Запись — в `dock()`:
   снапшот цен станции целиком, перезаписывая прошлое наблюдение этой станции.
2. **Сейв.** Поле в `SaveGame`, запись в `saveNow()`, восстановление в `continueGame()`.
   `SAVE_VERSION = 9`; `validateSave` при v8 подставляет `{}`.
3. **Шина.** В `MapSnapshot` добавляем `intel: { dockableId: string; name: string; systemId: string;
   t: number; prices: ... }[]` — собираем в методе, формирующем карту (рядом с `minimapData`,
   строка ~3126), отдаём только станции с записанными наблюдениями.
4. **UI.** В `StarMap.tsx` на вкладке «Система» под чипами систем — сворачиваемый блок
   «Рынки»: таблица станций выбранной системы (имя, по каждому товару цена покупки/продажи,
   возраст данных вида «12 мин назад»). Старые данные (старше ~10 мин игрового времени)
   визуально приглушить + пометка «устарело». Вкладку «Галактика» не трогаем.
   Стили — в существующей манере `sm-*` классов из `src/index.css`.
5. **Товары** берём из `GOODS` (config.ts), порядок колонок = порядок GOODS.

### Приёмка
- Стыковка со станцией → на карте появляются её цены; повторная стыковка обновляет.
- Перезапуск игры (сейв v9) — разведка на месте; загрузка сейва v8 — игра работает, разведка пустая.
- Станция без визита показывает «нет данных».
- `npm run check` чисто; регрессия 7/7 зелёная: `npm run verify && npm run balance &&
  npm run fleet && npm run focus && npm run smuggle && npm run loot && npm run watch`.
- Прод-сборка `npm run build` собирается, дебаг-мосты в ней отсутствуют (гейт BRIDGES не трогать).
